# 一期之后的能力扩展（不计入本包已验收范围）

一期达成的是“已支持方法上的全生命周期闭环”，不是全协议/全漏洞类型覆盖。以下只在 ENG-19 的有限开放门禁通过后，按新的版本化工单实施。

| 方向 | 可复用底座 | 必须新增的验收 |
|---|---|---|
| 方法库扩展 | 实验/证据/验证器契约 | 每个方法明确适用对象、前提、有效阴性、反证、误报边界、预算、数据最小化与清理；用未见变体评测 |
| 更多非破坏性观测适配器 | grant、请求计数、outbox | 每个协议真实连接范围、超时、速率和证据 schema；不因工具标签 ReadOnly 直接自动批准 |
| 浏览器工作流 | 受控身份与任务上下文 | 主文档/子资源/下载/WebSocket 等全部执行通道；会话隔离、实际出口、取消、敏感数据和提示注入场景 |
| 受审进程执行 | execution/attempt/fencing | OS 隔离、进程树回收、权限最小化、文件与网络控制；可解析命令不等于具备完整沙箱 |
| 远程 MCP 工具 | 方法白名单、版本、审计 | 服务端授权边界、真实参数副作用、取消/对账能力与服务身份；无法提供能力则不允许自主执行 |
| 经验与评分优化 | 条件化证据、日志和评测 | 历史经验仅作方法/优先级参考；不形成当前目标真值；用共同安全底座的消融检验质量和成本 |

任何新方向不能借“上一版已授权”扩大目标、凭据、业务影响或数据范围。扩展审批应具体到工具/方法/环境/模型版本，不按“全流程渗透”一次性无限批准。
