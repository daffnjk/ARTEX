# M2.3 — Read-only inspection surface (+ scoped integrity) 

Predecessors: M2.2, M1b.3b (DONE).

## Delivered

- GET /api/tasks/{id}/research/inspection (read-only, authed like sibling task
  routes): completion facts (status / completed_at / completed_source
  provenance), task-scoped graph integrity report, append-only evaluation
  archive rows (with timestamps), acceptance version history (with
  current-pointer). Assembly lives in a pure function
  (buildResearchInspection) tested against real PG without server bootstrap;
  the HTTP handler is a thin wrapper (consistent with existing server test
  coverage).
- db: TaskIntegrityReportScoped (per-task/exploration variants of the
  integrity checks; the cross-table finding_node_broken audit stays
  global-only), HarnessAcceptanceTaskHistory + EvaluationRecords (timestamped
  rows for the surface).
- Runner + CI: inspection test runs inside scripts/test-research-pg.sh (skip =
  failure) and thus the research-postgres CI job.

## Controlled completion-evaluation integration (scope decision, recorded)

The completion path consumes CURRENT frozen acceptance versions atomically
(M1b.3b). Requiring a confirm EvaluationRecord for completion is deliberately
NOT wired: EvaluationReport is not a release token (M1a rule), and the
condition-invalidation semantics that would make evaluations authoritative
live in M3.2. Deferred there with this note.

## UI

The web UI for this surface is deferred (browser-rendered acceptance required
by the frozen contract's UI rule); the JSON surface is the deliverable here.
