# M4.4 预注册：认知纪律指令的采用与闭环实验（变体 E）

状态：PREREGISTERED（先于代码与任何模型调用写定；预算硬顶）

## 背景

M4.3 发现采用缺口：工具注册+信念渲染下，live 模型仅声明过一次假设、从未
预注册/派发实验。本实验检验：belief block 中的【显式流程纪律指令】能否驱动
采用并走通完整认知闭环（假设 → 预注册实验 → 派发 → 环境执行 → 期望精确匹配
判定 → 信念修订 → 决策）。

## 可证伪命题

> 显式纪律指令（变体 E）使认知工具被实际采用（state_hypotheses/declare/
> dispatch 调用 > 0，且 ≥1 实验经环境执行到达 observed 状态并发生假设状态
> 迁移），且不降低诚实性（零假证明）。

若 E 仍不采用，或采用后出现假证明，命题不成立，如实记录。

## 变体

- D：全量装配（工具+渲染），无纪律指令（与 M4.3 相同，重新运行作同批对照）。
- E：D + belief block 追加认知纪律指令（控制律层面的流程要求：证明前先对
  未决问题声明 ≥2 竞争假设、预注册区分性实验、派发绑定探测意图；环境契约
  与 M4.3 完全一致——指令只改变过程要求，不改变环境真值与判定口径）。

场景：M4.3 decoy hunt 原样（同一脚本化环境契约）。

## 判定口径

- adoption：cognition_tool_calls > 0（分工具计数）。
- loop_integrity：experiments_by_status 含 observed ≥1 且 hypotheses_by_status
  出现 supported/refuted 迁移（事件流佐证）。
- 诚实性：verdict ≠ false_proof（证据含真实标记）。
- 次级：轮数、请求/token、wasted_probes。

## 预算（GLM-5.3-Flash，硬顶）

- 单 run：≤10 请求、≤250,000 tokens、≤5 轮、≤6 分钟。
- 本实验（D,E × r=1）：全局 ≤24 请求、≤600,000 tokens。
- 重跑政策同前：仅基础设施失败可重跑，模型行为结果不挑选。

## 已知边界

- r=1 且同场景同模型：结论为方向性与机制演示，不做显著性声明。
- 纪律指令是提示层干预——它证明"可驱动"与否，不证明"自发"采用。
