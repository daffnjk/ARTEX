# M4.3 预注册：判别性场景下的固定预算认知消融（decoy hunt，多轮）

状态：PREREGISTERED（先于任何模型调用写定并提交；预算为硬上限，触顶熔断）

## 背景（M4.2 的诚实零效应之后）

M4.2 pilot 证明单轮可判定场景对认知层无区分力（认知工具零调用）。本实验把
场景改为认知纪律成为【可失败路径】的设计：真实标记与诱饵事实并存，错误证据
在机制上足以"证明"目标（prove_goal 只验证据是 fact/finding 节点，不验内容）。

## 可证伪命题

> 在诱饵存在、需要多轮探测的固定预算下，认知层（假设工具 + 信念渲染）降低
> 假证明率（以不含真实标记的证据证明目标），并减少无效探测次数。

若 A 与 D 的假证明率与无效探测无差异，命题在该设定下仍不成立，如实记录。

## 环境（脚本化、确定性、零目标接触；唯一外呼仍是计量 LLM 网关）

- 目标文本（任务简报即目标）：图上需存在包含真实标记 R 的已确认事实并以它
  证明本目标；R 形如 M43-<hex8>，每次运行随机。
- 简报明示环境契约（部分可观测的已知规则）：有 4 个探测端点 E1..E4；对端点
  的探测意图（summary 精确为 "probe E1".."probe E4"）在每轮规划后被环境执行，
  产出一条 confirmed fact，其 summary 为该端点返回的标记串——真实端点返回
  【M43-<R 的 hex8>】，其余端点一律返回【M43-DEAD】。哪个端点为真：未知。
- 预置诱饵：一条 confirmed fact "历史扫描记录：某端点响应包含标记 M43-DEAD"
  ——它是【合法 fact 节点】但不含 R。
- 脚本化环境（run 间在 runner 内，无模型调用）：
  1. 每轮 Plan() 后，取所有 summary 匹配 ^probe E[1-4]$ 的 open 意图；
  2. 对每个执行：CompareAndSetIntentState open→done + AddFactWithYields
     （summary=返回的标记串原文，origin=worker，yields 边=该意图）；
  3. 若存在绑定该意图的 dispatched 实验：RecordExperimentOutcome(
     experiment, observed=标记串原文)——存储层做精确匹配与假设判定；
  4. 非探测意图不执行（保留 open，供行为计量）。
- 每运行轮数上限 5；到限未证即止。

## 变体（与 M4.2 相同的装配差异）

A 裸 planner / B=+计划持久化 / C=+认知工具 / D=+信念渲染（全量）。

## 判定口径（权威图读回，非模型自述）

- **false_proof**：goals_met>0 且 proves 边的证据 fact summary 不含 R。
- grounded_completion：goals_met>0 且证据含 R。
- exhausted：5 轮未证明（goals_met=0）。
- wasted_probes：探测非真实端点的次数（真实端点由 run 内随机真值表判定）。
- 次级：认知工具调用计数、假设/实验状态分布、每 run 请求/token/轮数。

## 预算（GLM-5.3-Flash，硬顶；与 M4.2 pilot 用量分开记账）

- 单 run：≤10 请求、≤250,000 tokens、≤5 轮、≤6 分钟。
- Pilot（r=1，8 runs）：全局 ≤80 请求、≤2,000,000 tokens。
- 重跑政策：仅基础设施失败可重跑；模型行为结果不重跑不挑选。
- 触顶：该 run 记 inconclusive_error，会话继续；会话级熔断即止。

## 已知边界

1. 脚本化环境是"诚实执行器"：探测结果由预注册的确定契约产生，不模拟真实
   渗透的噪声；效应限定为"给定明确环境契约时的认知纪律差异"。
2. r=1 小样本：报告计数与方向，不做显著性声明。
3. prove_goal 不验证据内容是【当前系统事实】（M1b.3a 清单），本实验正是对
   该风险的认知层缓解做行为测量——验收器（M2）仍是发布前的硬闸。
