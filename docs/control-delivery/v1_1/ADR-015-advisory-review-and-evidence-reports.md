# ENG-15: frozen advisory sessions and mechanical conclusions

Controlled review packets extend the existing ReviewPacket/hypothesis_reviews paths. They contain host captures, their digests/attempt lineage/withdrawals, frozen acceptance and deterministic claim archives. Planner facts, conversation history and self-written PASS are excluded. Packets are bounded (64 observations,100 claims/standards,4 MiB raw capture; optional model input2 MiB). A task-scoped host capability assigns a UUID session and appends session_created before any optional model request; archiving rechecks the entire packet digest under the task lock. Stale standards, context or evidence cannot reuse a session. Archives remain append-only; the legacy review writer refuses controlled tasks.

The server only issues the capability from its private authenticated administrator context. Reviewer/Worker context or model JSON cannot assign identity, approve methods or write a review. The optional Reviewer invokes the configured metered provider once, with no tools or tool loop, rejecting nontext/tool output and authority-shaped JSON. Actual transport retries retain normal budgeting; review session IDs appear in budget attribution. Host model identity and ledger source are archived. All such sessions are explicitly same_host_advisory and independent=false: they are not independent engineering approval or a distinct trust domain. No real model service was called in these tests; a localhost OpenAI-format fixture exercises actual SDK/transport/metering.

The only new mechanical criterion is http.body.sha256/v1: exact captured response-byte comparison against a frozen body_sha256 proposition. Identity/completeness/context gates still run in CommitValidatedOutcome; healthy scoped inequality may be a negative about those bytes, not target safety or impact. Unknown business criteria stay unimplemented/manual. The capture bridge invokes only this installed deterministic verifier when a matching frozen standard exists. A model review never writes a formal claim or permission.

The existing report route lists each displayed conclusion with criterion/context and evidence digest links, raw captures/counterevidence, unknowns and cleanup handoff. The authenticated task-scoped download returns original bytes with no-store/nosniff/download headers; withdrawn/foreign references refuse. Packet size limits fail closed rather than silently dropping evidence; larger historical exports require bounded pagination in the operations surface. No global coverage, recall or external effect guarantee is inferred.

Migration adds review provenance to the existing append-only archive. Rollback can disable advisory review, never bypass deterministic evidence or authorization gates. Independent engineering review remains pending.
