# ENG-13: durable feedback, bounded planning and shadow proxies

Host feedback is typed: valid result/negative replan, invalid premise refresh, unavailable tool choose a supported method, wait timeout collect the original execution, policy denial pause that branch, rate limit cool down, uncertain effect reconcile the original. Worker failures persist a host event and notify the live task immediately. Existing recovery polling remains a fallback, not an alternate permission or execution path. The Worker execution-tool allowlist is unchanged.

Before controlled Planner calls, a task-root transaction consumes bounded outbox feedback, captures separate collect and new-work queues, current evidence watermark and request/model-request consumption, then persists window-v1 state. Feedback backlog and cooldown prevent model calls; three empty planning windows pause further calls. New valid captured evidence resets stagnation regardless of whether it was predicted. Already running or uncertain executions force collection/reconciliation before new experiments. The actual add_intent tool is bounded to one intent per permitted round. The persisted host feedback block replaces the old unconditional 'must generate directions' instruction.

proxy-v1 records bounded, explainable discrimination/goal/coverage/cost/risk/repetition components after hard filtering. Same predictions add no discrimination; local adapter/method/identity/context/budget/precondition/unknown-effect gates apply first. Scores are explicitly uncalibrated and shadow-only: no sorting or dispatch change, no claimed EIG or convergence. Malformed experiment actions are retained as excluded shadow candidates, never interpreted as commands. Unknown DNS/peer authorization is still enforced by the actual pinned adapter before I/O.

State and snapshots reuse the existing task/outbox/experiment paths with additive tables. Rollback may disable proxies, never the runtime authorization or unknown-effect fence. Independent review pending. No real model service is used in these fixtures.
