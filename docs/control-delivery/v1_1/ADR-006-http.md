# ADR-006: bounded loopback HTTP and local request-start supervision

Only http.get v1 with anonymous identity is supported. Target/policy/grant come from a host port, not model-supplied capability fields. Model headers, proxy configuration, arbitrary credentials and executables are absent. The adapter accepts only localhost/loopback, validates every logical target, every resolved IP and every redirected port. Non-ASCII/encoded/query/resource-scoped targets remain unsupported.

Each hop gets a fresh transport, no proxy, no connection reuse or automatic redirect, no automatic decompression, bounded headers, fixed Host and TLS server name, certificate verification, and a DialContext that connects directly to an approved IP literal. No second DNS lookup occurs after checking. All returned addresses must be authorized; mixed IPv4/IPv6 permission sets are rejected. Response evidence retains at most 64KiB per hop and is marked incomplete on overflow or read failure; an additional byte is read only to detect truncation. The response_bytes resource tracks retained evidence bytes, not total wire traffic or kernel buffering. Overall wall time is three seconds and at most three requests, within the persisted grant expiry.

Supervisor serializes request-start permission and the host revocation callback, records active local calls, cancels active contexts, and independently polls grant validity. Already permitted/in-flight requests may still arrive after revocation; there is no external exactly-once or instantaneous remote rollback claim. Tests confirm cancellation by observing the actual fixture connection close, within a one-second bound on this platform. Local read completion requires the body to be closed; it does not certify remote mutable resources were cleaned.

Capabilities stay staged: no server task execution mode is exposed before ENG-07 integration. Adapter rollback disables controlled execution rather than substituting an unrestricted HTTP client. Existing traffic/guard remain legacy infrastructure and are not mislabelled as enforcing this grant.
