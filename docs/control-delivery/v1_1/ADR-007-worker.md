# ADR-007: actual Worker assembly with no unrestricted fallback

Controlled mode is determined from the live task/exploration binding at every Planner/Worker/MainAgent invocation. A controlled Worker requires an explicitly wired host tool factory; a legacy/unbound worker refuses it. The factory validates host RunInfo and task-owned running intent. No model field supplies task/exploration/attempt/grant authority.

The real Worker runs only control_action, normal SDK permission mode, no SDK TodoWrite, WebFetch/search, background tasks, skills, MCP, filesystem or shell tools. Augment/resolve are bypassed for controlled runs; server callbacks additionally refuse controlled augmentation before loading plugins. Unknown tool calls stay unavailable rather than being translated into shell. Planner retains only scoped graph/cognition/intent tools and existing task-plan scratchpad; formal proof and arbitrary asset/tool writes are absent. External noa/cold compaction is disabled; normal provider compaction remains budgeted through physical-request guards. The unadapted MainAgent path is refused.

control_action executes DecodeProposal -> atomic admission -> durable attempt claim -> grant-checked local HTTP -> atomic result/attempt/budget settlement and outbox. Grant expiry and epoch stay frozen. The result is not yet a formal validated claim; trusted observation/evaluation integration follows in ENG-09/10. Outcome persistence never calls separate independently committing settlement methods.

The authenticated approve/revoke handlers are mounted now; successful approve invalidates cached task bundles, and revoke serializes DB commit with the same process supervisor that gates local request starts. Already-started requests can have late effects. Legacy running tasks cannot be relabelled by approval. There is no default task-mode conversion.

Unadapted main/manual, retest creation/continuation and global asset enrichment are denied for controlled tasks, with audit events. Controlled-origin asset markers survive task unlink/deletion so queued global probes do not silently fall back to legacy authority. This can conservatively suppress legacy enrichment for an asset shared with controlled work; new adapter capabilities must be explicitly implemented, not enabled by removing the marker. No general OS sandbox is claimed.

First real Worker integration uses a scripted in-memory provider and actual localhost fixture request. It verifies one target hit, a persisted execution and attempt, plus refusal of unknown tools and missing/foreign task context. This is not a real-model behavior trial. SDK TodoWrite injection was caught by the unchanged strict tool inventory test and removed; initial failure receipt is retained.
